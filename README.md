# Maxclean

Анонимный браузер для Android: встроенный Tor с мостами, блокировщик рекламы и трекеров, без аккаунтов и без следов на телефоне.

Весь код браузера лежит в этом репозитории. Его можно прочитать, проверить и собрать самому.

## Скачать

Две версии из одного кода, с одной подписью. Любая ставится поверх другой, настройки сохраняются.

| Версия | Для кого | Файл |
|---|---|---|
| **Maxclean** | Лёгкая: простой тёмный интерфейс, все функции защиты | [`Maxclean.apk`](../../releases/latest/download/Maxclean.apk) |
| **Maxclean Full** | То же плюс оформление: светлая и тёмная темы, цвета, 5 иконок на выбор, анимации | [`Maxclean-Full.apk`](../../releases/latest/download/Maxclean-Full.apk) |

Все версии и контрольные суммы (`SHA256SUMS.txt`) — на [странице релизов](../../releases). Android 8.0+.

## Что умеет

- **Tor внутри, включён сразу.** Весь трафик браузера (страницы, картинки, скрипты, DNS) идёт через сеть Tor. Пока Tor не подключился, ничего не загружается, поэтому настоящий IP не утечёт. Работают сайты `.onion`.
- **Мосты Tor** для стран и сетей, где Tor заблокирован: встроенные Snowflake и obfs4 от Tor Project ([`assets/bridges.txt`](app/src/main/assets/bridges.txt)) или свои строки (obfs4, WebTunnel, Snowflake) с [bridges.torproject.org](https://bridges.torproject.org) или из Telegram-бота @GetBridgesBot.
- **Цепочка прокси перед Tor** (xray, sing-box, v2rayNG, Hiddify): до 5 прокси подряд, SOCKS5 или HTTP, с логином и без ([`ProxyChain.java`](app/src/main/java/az/maxclean/browser/ProxyChain.java)). Без Tor через цепочку идёт сам браузер. Прокси помогают обойти блокировки, а анонимность даёт Tor: первый прокси в цепочке видит ваш настоящий IP.
- **Прокси после Tor** — для сайтов, которые не пускают Tor. Такой прокси видит, что вы открываете, поэтому анонимности меньше; браузер об этом предупреждает.
- **Без DNS-утечек.** Имена сайтов передаются в Tor и по цепочке прокси как имена и разрешаются на выходе, а не у провайдера. Меню → «Проверка утечек» открывает независимые тесты, где это видно.
- **Без аккаунтов и статистики.** В приложении нет регистрации, аналитики и запросов к серверам разработчика. Единственное разрешение — доступ в интернет.
- **Без следов.** Cookies, кэш, локальное хранилище и история стираются при закрытии вкладки и при каждом запуске. Резервное копирование в облако отключено.
- **Блокировщик.** Отдельно включаются блокировка рекламы, трекеров и аналитики, пикселей соцсетей, крипто-майнеров, всплывающих окон и баннеров про cookies ([`assets/filters`](app/src/main/assets/filters)). Можно добавить свой список доменов.
- **Защита от отпечатка устройства:** одинаковые параметры железа, скрытые данные батареи и сети, общий видеочип вместо реального, шум при чтении canvas, общий User-Agent ([`assets/fingerprint.js`](app/src/main/assets/fingerprint.js)).
- **Профили устройств:** браузер может представляться Samsung Galaxy S23, Google Pixel 8 или Redmi Note 10 Pro. Все значения в профиле согласованы, а не случайны: случайные значения выделяли бы вас из толпы ([`Disguise.java`](app/src/main/java/az/maxclean/browser/Disguise.java)).
- **Местоположение для сайтов:** сайты, которые спрашивают, где вы, получают выбранный город или свои координаты, а не ваше настоящее место.
- **Только HTTPS:** незашифрованные страницы и их части открываются по HTTPS или блокируются (кроме `.onion`, где шифрует сам Tor).
- **Отключён WebRTC** (иначе сайт может узнать IP даже через Tor) и Safe Browsing (он отправляет адреса в Google).
- **Предупреждение об устаревшем движке:** если системный WebView старше года, браузер об этом скажет.
- **13 поисковиков** и свой адрес поиска. Встроенный поиск Maxclean — это DuckDuckGo без JavaScript через его официальный `.onion`-адрес.
- **Открытый код прямо в приложении:** меню → «Код браузера». Там же можно писать свои скрипты и стили для страниц.

## От чего защищает, а от чего нет

| Угроза | Защита |
|---|---|
| Провайдер видит, какие сайты вы открываете | ✅ Tor: провайдер видит только зашифрованное подключение к Tor (с мостами — даже не к Tor) |
| Сайт узнаёт ваш IP | ✅ Tor, плюс отключённый WebRTC |
| Реклама, трекеры, пиксели соцсетей | ✅ блокировщик, списки открыты |
| Следы на телефоне после закрытия | ✅ всё стирается; диск очищается и при запуске |
| Узел выхода Tor читает незашифрованный трафик | ✅ режим «только HTTPS» |
| Отпечаток устройства | ⚠️ снижается, но не так надёжно, как в Tor Browser |
| Уязвимости движка браузера | ⚠️ движок — системный Android WebView, его обновляет Google Play. Maxclean предупреждает, если он устарел |
| Другие приложения на телефоне | ❌ Maxclean защищает только себя, это не VPN. Для всего телефона используйте Orbot в режиме VPN |
| Вы сами входите в аккаунт на сайте | ❌ сайт будет знать, что это вы — анонимность это не отменяет |

Если от анонимности зависит ваша безопасность, используйте Tor Browser.

## Как проверить, что браузер безопасен

1. **Прочитайте код.** Логика браузера — это файлы в [`app/src/main/java/az/maxclean/browser`](app/src/main/java/az/maxclean/browser):

   | Файл | Что делает |
   |---|---|
   | `MainActivity.java` | вкладки, адресная строка, меню, настройки WebView |
   | `TorProxy.java` | запуск Tor, мостов и направление трафика через них |
   | `Bridges.java` | мосты Tor и настройки прокси |
   | `ProxyChain.java` | цепочка прокси: локальный SOCKS5-сервер на 127.0.0.1 |
   | `Disguise.java` | профили устройств и местоположение для сайтов |
   | `Palette.java`, `Icons.java` | оформление версии Full: темы, цвета, иконки |
   | `AdBlocker.java` | блокировка доменов из [`assets/filters`](app/src/main/assets/filters) |
   | `Wiper.java` | стирание cookies, кэша и данных |
   | `SearchEngines.java` | список поисковиков |
   | `SettingsActivity.java`, `Prefs.java` | настройки |
   | `CodeActivity.java` | просмотр кода и свои скрипты |

2. **Посмотрите разрешения** в [`AndroidManifest.xml`](app/src/main/AndroidManifest.xml): там только `INTERNET` и `ACCESS_NETWORK_STATE`.
3. **Проверьте зависимости.** Все сторонние библиотеки перечислены в [`app/build.gradle`](app/build.gradle), а их контрольные суммы SHA-256 зафиксированы в [`gradle/verification-metadata.xml`](gradle/verification-metadata.xml). Если хоть один скачанный файл не совпадёт, сборка остановится. Контрольная сумма самого Gradle зафиксирована в `gradle-wrapper.properties`.
4. **Сравните APK со сборкой GitHub.** Каждый APK в [Releases](../../releases) собирается автоматически из этого кода на серверах GitHub ([`.github/workflows/build.yml`](.github/workflows/build.yml)). В журнале сборки и в файле `SHA256SUMS.txt` указаны контрольные суммы SHA-256 обеих версий.
5. **Проверьте подпись.** Настоящие сборки Maxclean подписаны одним ключом. SHA-256 сертификата:

   ```
   68:31:B8:E8:9B:74:8A:5D:26:D8:6D:4E:4A:AE:5A:97:F2:1E:2D:1C:B1:97:EB:15:AD:73:C4:F0:DB:A1:AE:B3
   ```

   Обе версии подписаны им. Проверить можно командой `apksigner verify --print-certs Maxclean.apk` или приложением AppVerifier. Если сертификат другой, это не наша сборка.
6. **Соберите сами** (нужны JDK 17+ и Android SDK):

   ```bash
   ./gradlew assembleLiteRelease assembleFullRelease
   ```

   Без нашего ключа APK подпишется отладочным ключом, а код и поведение будут те же.

## Как сделан

Код написан с помощью ИИ (Claude) и открыт полностью именно поэтому: доверять стоит не автору и не ИИ, а коду, который каждый может прочитать.
