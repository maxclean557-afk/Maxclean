# Maxclean

Анонимный браузер для Android: встроенный Tor, блокировщик рекламы и трекеров, без аккаунтов и без следов на телефоне.

Весь код браузера лежит в этом репозитории. Его можно прочитать, проверить и собрать самому.

## Что умеет

- **Tor внутри.** Весь трафик (страницы, картинки, скрипты, DNS) идёт через сеть Tor. Пока Tor не подключился, браузер ничего не загружает, поэтому настоящий IP не утечёт. Работают сайты `.onion`.
- **Без аккаунтов и статистики.** В приложении нет регистрации, аналитики и запросов к серверам разработчика. Единственное разрешение — доступ в интернет.
- **Без следов.** Cookies, кэш, локальное хранилище и история стираются при закрытии вкладки и при каждом запуске. Резервное копирование в облако отключено.
- **Блокировщик.** Отдельно включаются блокировка рекламы, трекеров и аналитики, пикселей соцсетей, крипто-майнеров, всплывающих окон и баннеров про cookies. Можно добавить свой список доменов.
- **13 поисковиков** и свой адрес поиска. Встроенный поиск Maxclean — это DuckDuckGo без JavaScript, а при включённом Tor — его официальный `.onion`-адрес.
- **Дополнительная защита:** отключение WebRTC (иначе сайт может узнать IP даже через Tor), общий User-Agent вместо модели телефона, режим «только HTTPS», запрет скриншотов, отключённый Safe Browsing (он отправляет адреса в Google).
- **Открытый код прямо в приложении:** меню → «Код браузера». Там же можно писать свои скрипты и стили для страниц.

## Как проверить, что браузер безопасен

1. **Прочитайте код.** Логика браузера — это девять файлов в [`app/src/main/java/az/maxclean/browser`](app/src/main/java/az/maxclean/browser):

   | Файл | Что делает |
   |---|---|
   | `MainActivity.java` | вкладки, адресная строка, меню, настройки WebView |
   | `TorProxy.java` | запуск Tor и направление трафика через него |
   | `AdBlocker.java` | блокировка доменов из `assets/filters` |
   | `Wiper.java` | стирание cookies, кэша и данных |
   | `SearchEngines.java` | список поисковиков |
   | `SettingsActivity.java`, `Prefs.java` | настройки |
   | `CodeActivity.java` | просмотр кода и свои скрипты |

2. **Посмотрите разрешения** в [`AndroidManifest.xml`](app/src/main/AndroidManifest.xml): там только `INTERNET` и `ACCESS_NETWORK_STATE`.
3. **Сравните APK со сборкой GitHub.** Каждый APK в [Releases](../../releases) собирается автоматически из этого кода на серверах GitHub (см. [`.github/workflows/build.yml`](.github/workflows/build.yml)). В журнале сборки и в файле `Maxclean.apk.sha256` указана контрольная сумма SHA-256, её можно сравнить со скачанным файлом.
4. **Соберите сами** (нужны JDK 17+ и Android SDK):

   ```bash
   ./gradlew assembleRelease
   ```

   Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

## Чем Maxclean не является

Maxclean работает на системном движке Android WebView. Это не Tor Browser: он хорошо защищает от слежки провайдера, рекламных сетей и трекеров, но не защищает от продвинутого снятия «отпечатка» устройства так же надёжно, как Tor Browser. Если от анонимности зависит ваша безопасность, используйте Tor Browser.

Загрузка файлов отключена, чтобы на телефоне не оставалось следов.
